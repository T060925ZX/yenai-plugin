# 自定义邮件模板使用说明

## 📁 文件位置

将自定义的HTML邮件模板文件放在 `config` 目录下。

## 📝 快速开始

### 1. 复制示例文件

```bash
# 复制示例模板
cp config/email-template-example.html config/my-template.html
```

### 2. 编辑模板

用文本编辑器打开 `my-template.html`，修改HTML内容。

在需要显示动态内容的地方使用变量：
- `{code}` - 验证码（如：123456）
- `{groupId}` - QQ群号
- `{userId}` - 用户QQ号
- `{expireTime}` - 有效期（秒）

### 3. 配置使用

#### 方法一：锅巴配置（推荐）
1. 进入锅巴配置界面
2. 找到"群管配置" → "邮箱验证码配置"
3. 邮件模板风格：选择 **自定义模板**
4. 自定义模板文件名：输入 `my-template.html`
5. 保存

#### 方法二：编辑配置文件
编辑 `config/default_config/groupAdmin.yaml`：
```yaml
groupVerify:
  emailVerify:
    emailTemplateStyle: "custom"
    customTemplateFile: "my-template.html"
```

## 🎨 模板示例

### 最简示例

```html
<!DOCTYPE html>
<html>
<body>
  <h1>入群验证</h1>
  <p>群号：{groupId}</p>
  <p>验证码：<strong style="font-size: 24px; color: blue;">{code}</strong></p>
  <p>有效期：{expireTime}秒</p>
</body>
</html>
```

### 完整示例

参考文件：`email-template-example.html`

包含：
- 渐变头部
- 群信息卡片
- 大字号验证码显示
- 有效期提示
- 温馨提示区域
- 底部版权信息

## ⚙️ 开发建议

### HTML结构
- 使用完整的HTML5文档结构
- 添加viewport meta标签以支持移动端
- 使用语义化标签

### CSS样式
- **必须使用内联样式**（style属性）
- 避免使用外部CSS文件
- 避免使用 `<style>` 标签（部分邮箱不支持）
- 使用通用字体：Arial, Microsoft YaHei等

### 兼容性
- 避免使用JavaScript
- 避免使用复杂的CSS3特性
- 图片使用base64编码或绝对URL
- 测试多个邮箱客户端的显示效果

### 响应式设计
- 使用百分比宽度
- 设置max-width限制最大宽度
- 使用媒体查询（部分邮箱支持）

## 🔧 调试技巧

### 1. 查看日志
系统会在加载模板时输出日志：
```
[邮箱验证]已加载自定义模板: my-template.html
```

如果加载失败：
```
[邮箱验证]自定义模板文件不存在: /path/to/file
[邮箱验证]将使用默认模板
```

### 2. 测试发送
让新用户进群触发验证邮件，检查：
- 邮件是否正常发送
- 变量是否正确替换
- 样式是否正常显示

### 3. 常见错误

**错误1：文件不存在**
```
解决：确保文件在 config 目录下，文件名正确
```

**错误2：变量未替换**
```
解决：检查变量名是否正确，必须是 {code} 格式
```

**错误3：样式不显示**
```
解决：确保使用内联样式，不要使用外部CSS
```

## 📌 注意事项

1. ✅ 文件必须放在 `config` 目录
2. ✅ 使用UTF-8编码保存文件
3. ✅ 变量名区分大小写
4. ✅ 修改文件后自动生效，无需重启
5. ❌ 不要删除示例文件（作为参考）
6. ❌ 不要在模板中使用脚本

## 🎯 最佳实践

1. **备份模板**：修改前备份原文件
2. **渐进修改**：从示例文件开始，逐步修改
3. **多端测试**：在QQ邮箱、163邮箱等测试
4. **保持简洁**：避免过于复杂的设计
5. **注释说明**：在HTML中添加注释说明

## 💡 高级技巧

### 条件样式

可以根据不同场景使用不同的样式：

```html
<!-- 验证码高亮显示 -->
<div style="background: {code ? '#e3f2fd' : '#f5f5f5'};">
  {code}
</div>
```

### 动态内容

虽然模板本身不支持逻辑，但可以通过变量传递更多信息：

```html
<p>欢迎用户 {userId} 加入群 {groupId}</p>
```
